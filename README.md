## 📜 Descrição

&ensp; O projeto desenvolvido pelo grupo **Rooster** tem como objetivo a criação de um sistema automatizado para a **classificação de fissuras em superfícies**, como em estruturas de concreto, utilizando técnicas de **visão computacional** e **aprendizado de máquina**.

&emsp;A proposta surge da necessidade de agilizar inspeções visuais, que atualmente demandam tempo e estão sujeitas a erros humanos. Com o uso de modelos de machine learning, é possível **classificar automaticamente as imagens** conforme o tipo de fissura (por exemplo, térmica ou por retração), tornando o processo mais eficiente e confiável.

### Objetivos principais
- Automatizar a análise visual de fissuras estruturais.
- Reduzir o tempo e o custo de inspeções manuais.
- Oferecer uma interface simples para upload, visualização e classificação de imagens.
- Gerar relatórios com base nas classificações.

### Tecnologias utilizadas
- Python 
- YOLO
- Flask
- React  
- Estrutura modular com pastas organizadas (`src/`, `docs/`, `runs/`, etc.)

### Funcionalidades principais
- Upload de imagens locais
- Visualização pré-classificação
- Classificação automática usando modelo treinado
- Correção manual da classificação (se necessário)
- Geração de relatório com as classificações realizadas

##  📁 Estrutura de pastas

Dentre os arquivos e pastas presentes na raiz do projeto, definem-se:

- <b>docs</b>: Documentação do projeto (guia de uso, arquitetura, etc.)

- <b>runs</b>: Armazenamento de execuções do modelo de classificação e detecção.

- <b>src</b>: Todo o código fonte criado para o desenvolvimento do projeto, incluindo backend, frontend e lógica de machine learning.

- <b>readme.md</b>: Documentação de apresentação do projeto (o mesmo que você está lendo agora).
